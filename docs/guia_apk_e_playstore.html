Parte A — Gerar APK pra instalar num Android de teste

Pré-requisitos

  • Flutter instalado e funcionando (flutter doctor sem erro vermelho).
  • No aparelho: Depuração USB ligada (pra instalar via adb) OU instalar de fontes desconhecidas liberado (pra instalar o .apk copiado direto).

Passo a passo

cd frontend
flutter pub get
flutter build apk --release

O APK sai em:

frontend/build/app/outputs/flutter-apk/app-release.apk

Com o aparelho por USB:

adb install -r build/app/outputs/flutter-apk/app-release.apk

Sem adb: transfira o .apk pro celular (cabo, Drive, WhatsApp Web) e abra o arquivo no aparelho.

Direto num device conectado:

flutter install -d <device-id>
Emulador via ./scripts/run_android.sh roda em modo debug — ótimo pra desenvolver, mas não gera artefato pra distribuir. Pra isso, use flutter build apk --release.

Se frontend/android/key.properties existir (existe), o build já sai assinado com a keystore de upload. Sem ele, cairia pro signing de debug — serve pra testar, mas não é o artefato final de loja.
