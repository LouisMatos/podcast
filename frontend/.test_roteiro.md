## Cenários de robustez (Common Mistakes)

### 13. Rede e cache
- [x] Ligar modo avião durante refresh — validado em device físico real: Home pull-to-refresh mostra "Sem conexão" (snackbar) sem travar, cache local permanece visível; Discover sem cache mostra estado de erro completo (ícone wifi-off, "Sem conexão", botão "Tentar de novo"); carrossel com cache prévio usa stale-while-revalidate normalmente
- [x] Desligar modo avião — **nota**: não atualiza sozinho ao reconectar (sem listener de conectividade ativo); precisa de nova interação (toque em "Tentar de novo" ou nova busca) — validado que a partir daí funciona normalmente. Comportamento aceitável, não é bug bloqueante, mas diverge do texto original do item ("atualiza assim que rede volta")
- [x] Timeout de rede em `/discover` (busca lenta) — não congela UI

### 14. Sheets e overflow
- [x] Fila com muitos itens — sheet abre e escala corretamente (720x1280)

- [x] Descrição de episódio longa — scroll funciona
- [x] Temporizador de dormir em device pequeno — layout não quebra (todas opções visíveis sem corte)

### 15. Download e persistence
- [x] Matar app durante download — reabrir e checar reconciliação (`reconcileStuckDownloads()`) — **validado**: download completou sozinho após `force-stop` + reabertura, sem ficar preso
- [x] Download pausado — retomar funciona — **bug encontrado e corrigido**: botão de download tratava estado `paused` chamando `download()` (nova tarefa) em vez de retomar a existente; agora chama `service.resume(taskId)` (novo método em `download_service.dart`), igual ao caminho já usado em `reconcileStuckDownloads()`

- [x] Deep link com `%` bruto no guid — não trava, fallback `/resolve/invalid`
