## Deep links (/resolve/*)

### 9. Deep link de podcast
- [ ] `adb shell am start -a android.intent.action.VIEW -d "podcastapp://podcast/<id>"` — resolve e abre `/podcast`

### 10. Deep link de episódio
- [ ] `adb shell am start -a android.intent.action.VIEW -d "podcastapp://episode/<id>?guid=<guid>"` — resolve e abre `/episode`

### 11. Deep link de feed RSS
- [ ] `adb shell am start -a android.intent.action.VIEW -d "podcastapp://feed?url=<url>"` — abre `/resolve/feed` → SubscribeFeedScreen

### 12. Deep link inválido
- [ ] `adb shell am start -a android.intent.action.VIEW -d "podcastapp://invalid"` — fallback `/resolve/invalid` + snackbar de erro

## Cenários de robustez (Common Mistakes)

### 13. Rede e cache
- [ ] Ligar modo avião durante refresh — não trava, cai pro cache
- [ ] Desligar modo avião — atualiza assim que rede volta
- [ ] Timeout de rede em `/discover` (busca lenta) — não congela UI

### 14. Sheets e overflow
- [ ] Fila com muitos itens — scroll funciona, não crash (720x1280 pequeno)
- [ ] Equalizador em device pequeno — layout não quebra
- [ ] Descrição de episódio longa — scroll funciona

### 15. Download e persistence
- [ ] Matar app durante download — reabrir e checar reconciliação (`reconcileStuckDownloads()`)
- [ ] Download pausado — retomar funciona

### 16. Deep link malformado
- [ ] Deep link com `%` bruto no guid — não trava, fallback `/resolve/invalid`
