# backend

Vazio de propósito.

O app (`../frontend`) é local-only na v1: sem login, sem sync, SQLite
embutido via `drift`. Não há servidor a construir ainda.

Esta pasta existe pra quando isso deixar de ser verdade — candidatos
naturais pra entrar aqui, nessa ordem:

1. Sync de assinaturas e progresso de escuta entre aparelhos
2. Conta de usuário
3. Recomendação / descoberta personalizada

Antes de começar qualquer coisa aqui: abrir um design (`docs/superpowers/specs/`)
como qualquer outra feature, não só sair escrevendo código de servidor.
